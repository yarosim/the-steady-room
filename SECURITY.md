# Security Policy
This is a static GitHub Pages site. It holds no user data or server code.
Checkout and payment run on Shopify (AlphaPath Digital); this repo stores no payment keys.

## Reporting a vulnerability
Use GitHub's **private vulnerability reporting** ("Report a vulnerability" under the Security tab). Please do not open a public issue.
We aim to reply within 7 days.

## Controls
Dependabot (actions), CodeQL, gitleaks secret scan, lychee link check, Shopify buy-link check, least-privilege workflow tokens, weekly scheduled re-scan.
